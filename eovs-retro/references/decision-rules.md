# 需求、生产、资金和碳的联动判断

## 市场预测：实际需求不是均分市场规模

全市场规模÷经营公司数只是假设均分的粗参考，不能当该公司准确需求。品牌、质量、售价、营销即时／递延效应、宏观变化和竞争共同影响结果。正式客服限制可卖量，不等同于需求。

优先用上一季本公司**真实需求**作为基线：

`本季基线需求 = 上季公司需求 × 本季市场规模 ÷ 上季市场规模`

这是比例外推，不是系统需求公式。价格、质量、广告或对手行为变化时必须修正；连续两季能接近实际也不能推出八季均准确。缺规模或上季需求时，不硬算精确值；售罄销量是需求的下界。

按当前价、中间价和较高价／较低价做少量候选，再分保守、基准、乐观情景。价格弹性缺证据时不给精确百分比。将预测与下季结算对照，记录误差，下一季修正；保留原预测，不用事后数字改成“原来预测准确”。

### 投放与人员

`每区可卖量 ≤ 预测公司需求，也 ≤ 正式已生效客服容量，也 ≤ 可售货量`

`每区新投放 = max(0，销售目标 − 本区可售旧成品)`

加总受全公司的旧成品＋本季产量限制。旧库存不能在生产目标和分货中重复扣／重复分配。

用本场生效规则区分正式人员和当季招的新员工。教材中每名人员最多卖10万是要核实的规则线索，不把人数报表所有人都当可服务人数。某区已有需求但卡服务上限，需要上一季提前招人；当季挪货不能解除这个限制。

### 三类经营状态

- 需求高于销量、货已卖完：查产能与有效人员，适度高价是否仍能卖完也值得比较；降价激发更多缺货需求未必有益。
- 某区缺货、另区积货：先核缺货区服务容量，再比较调货与提前招聘，算运输差与库存成本；新比赛不能用已知结算需求作赛前精确分货。
- 各区需求均已满足仍有余货：同价同需求下调货不增加总销量；比较改变价格、营销、人员与生产的组合。

## 定价与营销

每个季度分别列老师示范、自己的实际、对手公开报价、库存与环境。示范价格和广告投入只是候选起点；第三／四季广告为0不是禁投，第一季80万或第二季48万也不是统一答案。

广告应比较额外**可兑现销量**和贡献利润，受库存、人员及生产能力约束；有需求无货时，单纯刺激需求容易增加费用。把营销当季效果和后续品牌积累分开。研发要看质量差距、剩余兑现季度和可承受现金，不能把某一季利润高全归功于少研发。

在同路线或同市场机制已确认的对手中优先对标；跨组报价只能借鉴打法，不能直接推本队价格弹性。公开收入−净利是净扣减额，包含成本、税和可能的其他收入调整，不是某一项已知费用。

## 扩线与末季生产

权益达到某个门槛只说明可能具备扩线条件，不能自动买满。核新增线生效期、每班真实产能、班次上限、剩余使用期、材料与人员、需求、现金及新增碳成本。报告期末线数可能含下季才有效的新线。

`计划新增生产 ≈ 可兑现销售目标 − 可售旧成品`只是货量起点。完整利润比较还需：销售收入、原料平均成本、人工、班次、维护折旧、库存计价变化、仓储、碳履约、税、融资与评分。

最后一季也不能只喊满产或减产：有预计能卖的新增产出，核单件贡献覆盖增量成本；有旧货与不足需求，比较少生产及合理价格。成品按某个账面价留存会影响权益，减产不能把全部材料／人工节约直接加到净利。

若同时修改相邻两季，重新滚动库存和债务。不能第一季减掉的旧货在后一季再减一次，也不能把两次静态增益直接相加。

## 财务：钱、利润、权益和分数

基本核对：

- `期末权益 = 期末资产 − 期末负债`
- `期末权益 = 期初权益 + 净利润 − 分红 + 其他权益调整`
- `期初成品 + 生产 − 销售 ± 其他出入库 = 期末成品`

借入本金同时增加现金与负债；偿还本金同时减少两者，不能直接算利润费用。正常／异常利息、税、罚款与采购费用另核。卖货影响收入、库存转成本与现金，权益按实际净利变动。

季末有现金也可能季内缺钱。以本场到账比例与付款时点、可动用基本账户余额、获准普通贷款计算预算；交易账户资金是否能用需核划转规则。借款额度需要实际规则或页面证明，不保证预测缺口全部能借。

只有本场已验证“异常债下期并入普通债”“期初异常本金仍有利差”时，可用候选模型：

`滚入后的本金 = 上季正常债 + 上季异常债 + 新借款 − 还本金`

`利息 = 滚入后本金 × 普通季率 + 上季异常债 × (异常季率 − 普通季率)`

额外利差已经包含在总利息内。候选模型先逐季对实账，不把年利率直接当季利率，也不将一种平台版本的异常计息推广为全部版本。

少还本金的效应主要是预算、后续利息和评分。固定盘试算要更新随本金改变的利息和所得税；一季不还能否消除缺口应实算，不能只看还款金额。前季调整后，下季的还款建议重算。

总分按盈利、偿债、研发、营销、潜力、团队、碳等本场指标拆开。NPV的完整公式未知就说明未知；不要用末权益替代它。扣分转成团队指标后不能再从总分扣一遍，消除累计扣分也不一定等额加回。

## 碳：统一总口径与净口径

付罚款是付钱，补履约是交额度。欠碳不是欠银行同数量的元；罚款可能造成现金压力，但不能据欠吨数直接判断异常债。

两种等价口径仅在分配与扣旧欠正确对应时使用：

`含旧欠的总需求 = 本期排放 + 上期未补欠额`

`实际期末欠额 = max(0，总需求 − 实际履约CEA总量 − 实际合规使用CCER)`

CEA总履约量包含先补旧欠的部分，不能用“尚未提交的可用余额”代替。候选方案可以计算计划提交量，但要明确自动履约规则、可用余额、合法上限和实际能提交多少；未提交或保留出售的额度不算履约。

或按平台通知：

`期末欠额 = 通知当期应履约 − 已先处理旧欠后的净已履约`

**不要用含旧欠需求再减已扣旧欠的净供给。** 领取量、可用余额、实际提交和“净抵本期”不是同一个格子的通用答案。超额、出售、留存和负余额的表现需按版本核实。

逐季实际罚款核对缺口×本场每吨罚率。若罚金按收盘价倍数计，当季收盘价不等于竞价买入价；原局没有缺口时，不能从0罚款倒推出每吨罚率。

减产会改变本期排放；在免费CEA和CCER上限与产量／排放挂钩的版本，还要同步更新这些值。免费额度的整数舍入、CCER上限分母及舍入、累计旧欠如何处理要按平台核对。不能减产后仍保留原先已失效的免费额度／CCER提交量。

### CEA与CCER项目价格比较

早补欠額可能释放以后被旧欠占用的免费CEA，因此不止少罚当季一次。逐季滚动计算“有额度／无额度”的缺口与罚款差；在未来会清欠时停止重复计益，不将一吨额度直接乘所有剩余季度。

比较项目时，固定盘应明确固定什么：生产、总CEA、其他购入CCER、实际价量还是市场假设。项目产生的额度何时可用、每季合法抵扣量、过期及剩余资产必须明确。区分项目与另购CCER的省罚功劳。

`情景竞拍预算上界 = 预计少罚／替代采购价值 + 可兑现残值 − 运营／交易／融资／税等新增负担`

逐季建立两个独立账本，避免把节省罚款误算成“额度×罚率×所有剩余季度”：

|季|当期排放|总CEA履约量|合规CCER使用量|上季旧欠|期末缺口|每吨罚率|本季罚款|
|---|---:|---:|---:|---:|---:|---:|---:|
|基准方案Qn|按该方案生产算|按已核可用量与提交规则算|核实际可使用来源及抵扣上限|基准方案上季缺口|按总口径算|已核本季规则|缺口×罚率|
|有项目Qn|固定盘须与基准一致|与基准同样假设，另核腾出的结余|原CCER＋项目，仍受上限约束|有项目方案上季缺口|按总口径算|同一场景罚率|缺口×罚率|

每个账本单独将期末缺口、可留存CEA／CCER滚到下一季。项目没有可用产出、额度被上限卡住、未来本来就会清欠时，省罚可能为0。总价值先加两账本的逐季罚款差，再核替代采购；同一吨用于少罚和替代采购时不能重复计益。若竞拍价改变了后续借款与利息，报价上界需要迭代重算；不能用未扣融资成本的总省罚直接当安全报价。

当规则、需求或可成交碳数量不确定，给场景区间与缓冲，不称为稳赚安全线。先验证可成交性，再给具体报价候选；复盘不替用户竞拍。

## 证据表达

结论应是“实际数据支持什么、什么尚不确定”。静态改价、移货、减产、少还款和去掉项目的试算不能直接相加到最终权益，也不能声称等同重打一遍整局。保留有效打法，只修有证据的问题。
