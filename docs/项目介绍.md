# EOVS复盘Skill

**把八季度比赛看明白，把利润、现金和排名的差距算明白。**

这套Skill沉淀自我们一次**校赛总分第一**的EOVS实战案例。我们使用**Codex**完成逐季复盘，把数据收集、前五名对标、账务核查和反复讨论的决策问题，整理成了可以复用的分析流程。学校、队伍和原始数据保持匿名。

它最有价值的地方，是能把零散数据接成一条完整的经营链：**价格影响需求，人员和货量限制销量，库存牵动成本与现金，生产连着碳，融资再影响下一季。** 每个判断都要能说明依据，每个方案都要能解释条件，每一步填表都要告诉使用者从哪里取数据、为什么这样填、怎样核对。

第一名案例给了这套方法一个扎实的实战起点；真正让它值得继续用的，是它保留下来的检查习惯：不混淆需求和销量，不把还本金算成利润损失，不重复扣碳旧欠，不改权益结果凑数，也不把老师的示范数字背成八季固定答案。

## 可以帮你做什么

- **整场复盘**：从筹建期到第八季，分别解释自己的表现和前三／前五名的公开打法，找出领先、追近和失误发生在哪一季。
- **市场决策**：结合上季需求、市场规模、竞争报价、质量品牌、库存和正式人员，做需求情景，比较定价、营销和配货。
- **生产与碳**：一起重算产量、免费CEA、CCER抵扣上限、旧欠和逐季罚款，判断多生产的利润能否覆盖新增成本。
- **借还款与权益**：拆开本金、正常利息、异常利差、季内资金缺口与期末现金，解释钱和利润分别去了哪里。
- **表格教学**：打开当前版本，指出疑似错误，从输入和依赖追到结果；逐格说明填什么、保留什么公式、在哪里取数、怎样验算。
- **CCER项目比较**：核项目可用期和上限，滚动比较有项目／无项目的罚款及资金差，再给带条件的报价区间。

## 怎样调用

中文名：**EOVS复盘Skill**。英文调用：**`$eovs-retro`**。

可以直接这样说：

> 使用 $eovs-retro，结合本场数据、我的预测表和教学字幕，逐季复盘我和前五名。解释需求、定价、库存、借还款、权益和碳的问题，给出下一场改进顺序，并一步一步教我填表。不要修改原文件。

只问一个季度也可以：

> 使用 $eovs-retro，帮我比较第八季满产和减产。把售价、预计销量、旧库存、免费CEA、CCER上限和现金一起算，缺数据先列出来。

包内阅读顺序：`eovs-retro/SKILL.md` → 按任务读取参考文件 → 使用 `assets/report-template.md` 组织报告。需要机器核对时，再读 `references/data-schema.md` 并运行脚本。
